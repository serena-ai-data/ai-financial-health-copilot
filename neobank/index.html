01 · Product Brief

The product problem is cross-product, not feature-level.

Users can have good banking apps, good insurance apps and good investment apps and still lack one place that turns all of that information into a coherent financial decision.

Primary user

Working professionals who already use multiple digital financial products but are not financial specialists. They value speed, visibility, control and clear reasoning over financial jargon.

Job to be done

“Help me understand my overall position, identify what deserves attention first, and take the next step without losing control of consequential decisions.”

“I do not need six product dashboards. I need one reliable answer to: what should I pay attention to now?”
02 · Product Model

Three layers: context, decision, action.

The neobank is structured around a reusable decision layer that can sit across financial services instead of treating each feature as a separate destination.

01 · Financial context

Know what is true

Bank balances, cards, investments, policies, spending, savings and user-confirmed facts.

02 · Decision layer

Know what matters

03 · Launch Thesis

Ship a narrow loop, then earn the right to expand.

The roadmap is designed to test whether users trust and repeatedly use the cross-product decision layer before the product spends heavily on integrations or regulated execution.

Phase 1 · MVP

Understand

Manual / synthetic financial context, review, deterministic analysis, explainability and one prioritised next step.

Primary signal: activation → first useful insight
Phase 2

Connect

Add selected account / insurance data connections with consent, source traceability and exception handling.

Primary signal: lower input friction + repeat usage
Phase 3

Personalise

Use verified context to rank goals, nudges and product journeys without hiding uncertainty.

Primary signal: action engagement + retention
Phase 4

Execute

Introduce human-confirmed product hand-off or transaction flows only where compliance, suitability and operational controls are mature.

Primary signal: safe completion + low escalation
Decision Log

Key product trade-offs

Real integrations vs fast validationStart with structured input and synthetic data.Validate the cross-product decision problem before investing in connectors.
AI-generated score vs deterministic logicKeep consequential calculations deterministic.Reproducibility and auditability matter more than novelty.
Broad neobank vs narrow wedgeLaunch one coherent value loop first.A crowded feature menu does not prove users trust the decision layer.
Autonomous action vs user controlRequire explicit confirmation for consequential steps.Financial products should not turn ambiguous AI output into silent execution.

Experiment A

Dashboard vs priority-first home

Test whether leading with one next-best action improves comprehension and action review compared with a generic dashboard.

Experiment B

Manual input vs selective connection

Measure whether connecting only the highest-friction data source materially improves completion and repeat usage.

Experiment C

AI explanation depth

Test concise explanation by default with optional evidence / formula expansion versus fully detailed first-load output.
